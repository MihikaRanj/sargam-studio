# Sargam Studio

**An open-source web application for composing, playing, and exploring Hindustani classical music notation.**

Sargam Studio provides an interactive environment for musicians, students, and teachers to create Hindustani classical music compositions using Sargam notation, organize compositions by taal and section, hear their notation played back, and export their work as audio.

🌐 **Live Website:** https://sargam-studio.vercel.app/home

## Why Sargam Studio?

Hindustani classical music is traditionally taught and practiced through a combination of oral instruction and written Sargam notation. General-purpose music notation software does not always represent concepts such as swaras, saptaks, komal and teevra notes, taals, and different rhythmic subdivisions in an intuitive way.

Sargam Studio was created to explore how technology can make writing, hearing, and practicing Hindustani classical music more accessible.

## Features

- 🎵 Create compositions using Hindustani Sargam notation
- 🎼 Support for shuddha, komal, and teevra swaras
- 🎶 Multiple saptaks
- 🥁 Taal-based composition and playback
- ⏱️ Ekgun, Dugun, Tigun, and Chaugun rhythmic layouts
- 🎤 Aalap sections without a taal
- 🔊 Interactive playback of compositions
- 🥁 Tabla accompaniment
- 🎚️ Adjustable tempo
- ▶️ Playback of individual rows and sections
- 💾 Save compositions
- 🎧 Export compositions as WAV audio
- 📱 Responsive interface for desktop and mobile devices

## Supported Taals

Sargam Studio currently supports:

- Teentaal
- Ektaal
- Jhaptaal
- Rupak
- Keherwa
- Dadra

Additional taals and musical features are planned, and community contributions are welcome.

## Running the Project Locally

### Prerequisites

Install:

- Node.js
- npm

### Setup

Clone the repository:

```bash
git clone https://github.com/MihikaRanj/sargam-studio.git
cd sargam-studio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
