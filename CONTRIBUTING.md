# Contributing to Sargam Studio

Thank you for your interest in contributing to Sargam Studio!

Sargam Studio is an open-source project designed to make composing, playing, and exploring Hindustani classical music notation more accessible. Contributions are welcome from developers, musicians, students, teachers, and anyone interested in improving the project.

## Ways to Contribute

There are many ways you can help, even if you are not a developer.

### For Developers

You can contribute by:

- Adding support for additional taals
- Improving music and tabla playback
- Expanding Sargam notation capabilities
- Improving the user interface
- Improving mobile and responsive behavior
- Adding accessibility features
- Fixing bugs
- Improving performance
- Adding new practice or learning features

### For Musicians and Music Students

Technical experience is not required to contribute.

You can help by:

- Suggesting new taals or musical features
- Reporting incorrect notation or playback
- Suggesting improvements to the composition workflow
- Testing Sargam Studio with real compositions
- Suggesting features that would be useful for students and teachers
- Reporting bugs or confusing behavior

You can submit these suggestions through GitHub Issues.

## Getting Started

### 1. Fork the Repository

Use the **Fork** button on GitHub to create your own copy of Sargam Studio.

### 2. Clone Your Fork

```bash
git clone YOUR_FORK_URL
cd sargam-studio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Create a Branch

Create a branch for your change rather than working directly on the master branch.

For example:

```bash
git checkout -b add-new-taal
```

### 6. Make Your Changes

Make and test your changes locally.

Please try to keep each contribution focused on one feature, improvement, or bug fix.

### 7. Commit Your Changes

For example:

```bash
git add .
git commit -m "Add support for new taal"
```

### 8. Push Your Branch

```bash
git push origin add-new-taal
```

### 9. Submit a Pull Request

Open the Sargam Studio repository on GitHub and create a Pull Request from your branch.

Please include:

- A short description of what you changed
- Why the change is useful
- Any testing you performed
- Screenshots for visual changes, when applicable

## Reporting Bugs

If you find a bug, please create a GitHub Issue and include as much information as possible, such as:

- What you were trying to do
- What happened
- What you expected to happen
- Browser or device being used
- Steps that reproduce the problem
- Screenshots, if helpful

## Suggesting Features

Feature suggestions are welcome.

When creating a feature request, please explain:

- The feature you would like to see
- How it would help musicians, students, or teachers
- Any relevant Hindustani classical music concepts
- An example of how the feature might work

## Musical Accuracy

Musical accuracy is particularly important for Sargam Studio.

If your contribution changes notation, swaras, taals, tabla bols, rhythmic behavior, or playback, please describe the musical reasoning behind the change in your Pull Request.

Feedback from Hindustani classical musicians and teachers is especially welcome.

## Code Guidelines

When contributing code:

- Follow the existing TypeScript and React structure where possible
- Keep changes focused and understandable
- Test your changes before submitting a Pull Request
- Avoid committing passwords, API keys, credentials, or `.env` files
- Add comments where the musical or technical logic may not be obvious

## Questions

If you are interested in contributing but are unsure where to begin, look for GitHub Issues labeled:

`good first issue`

These are intended to be approachable starting points for new contributors.
